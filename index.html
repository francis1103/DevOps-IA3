Project Overview

Bridging Development and Cloud Operations

DevOps IA-3 solves the challenge of manual, error-prone server deployments by enforcing an automated continuous integration and continuous deployment (CI/CD) lifecycle powered by version control and declarative cloud infrastructure.

⚙️

Continuous Integration

Every code commit pushed to GitHub triggers automated checkout, syntax validation, and unit checks within a sandboxed Dockerized Jenkins environment.

  • Automated Git change detection
  • Linting and code structure tests
  • Immediate build feedback
🏗️

Infrastructure as Code

Cloud infrastructure is codified and versioned with HashiCorp Terraform, eliminating configuration drift and ensuring identical, reproducible Azure environments.

  • Declarative AzureRM definitions
  • Managed VNet, Subnet, NSG, & VM
  • Strict principle of least privilege
🚀

Automated Deployment

Pre-validated packages are securely transferred to the Azure Ubuntu host via SSH key authentication, followed by zero-downtime Nginx reloads and HTTP health probes.

  • SSH key-based authentication
  • Idempotent deployment scripts
  • Automated post-deployment verification

Step-by-Step

End-to-End Operational Workflow

How continuous integration and continuous deployment ensure rapid, safe, and verifiable delivery.

01

Code & Commit

Developer modifies the frontend application or deployment scripts on Windows 11. Changes are tested locally and committed to the Git repository.

02

Push to GitHub

Code is pushed to GitHub (francis1103/DevOps-IA3). The repository maintains code integrity and acts as the single source of truth.

03

Jenkins Triggers Pipeline

Jenkins detects the new commit via SCM polling or webhook, creates an isolated workspace, and checks out the exact commit SHA.

04

Validation & Security Scan

Jenkins validates HTML/CSS/JS syntax, verifies script execution permissions, checks Terraform configuration, and enforces zero-secret exposure policies.

05

SSH Package Transfer & Deploy

Using credentials stored in Jenkins' secure vault, Jenkins establishes an authenticated SSH session to the Azure VM (20.219.161.235) and synchronizes release files to /var/www/devops-ia3.

06

Service Reload & Health Verification

The deployment script reloads Nginx and performs an HTTP GET probe on port 80. If any step fails, the pipeline aborts immediately with diagnostic logs.
